Windows 与 macOS 排查 DNS 缓存：刷新、hosts 与 IPv6

编撰：Runway 使用手记 · 日期：2026年11月13日 · 预计阅读时间：5分钟

一、为什么会有缓存

系统和浏览器都会把域名解析结果缓存一段时间，减少重复查询。节点或规则变化后，旧缓存可能让你仍然访问到旧结果。

二、刷新系统缓存

Windows 在命令提示符里执行刷新 DNS 的命令；macOS 则通过终端命令重启相关服务。刷新后重新打开浏览器测试。

三、浏览器自己的缓存

浏览器还有自己的 DNS 缓存，可以在设置页中清除，或者重启浏览器、换用无痕窗口。

四、检查 hosts 文件

hosts 文件里的手动条目优先级很高。如果曾经添加过某个域名，它可能一直指向旧地址。把不需要的条目删除或注释即可。

五、IPv6 的影响

当 IPv6 解析未被客户端处理时，部分流量会绕过代理。可以先暂时关闭系统的 IPv6 做对比测试。

小结

缓存、hosts、IPv6 三项检查完，大部分“改了没效果”的问题都能找到原因。
