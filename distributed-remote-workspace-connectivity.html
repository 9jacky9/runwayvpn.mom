Git 克隆太慢怎么办：HTTP 代理与 SSH 代理的设置

编撰：Runway 使用手记 · 日期：2026年11月14日 · 预计阅读时间：5分钟

一、先判断是哪种地址

仓库地址以 https 开头的，使用 HTTP 代理配置；以 git@ 开头的是 SSH 方式，需要另外设置。判断清楚，才不会改错地方。

二、HTTPS 方式

在 Git 配置里设置 http.proxy 与 https.proxy，指向本地客户端监听的端口即可。只想对某个网站生效时，可以按域名单独设置，避免影响其他仓库。

三、SSH 方式

在 SSH 配置文件中为目标主机添加 ProxyCommand，通过本地代理端口转发连接。同一个主机下的所有仓库都会使用它。

四、常见错误

  • 端口号写错，或客户端没有开启对应的监听。
  • 代理类型不匹配，例如 SOCKS5 与 HTTP 混用。
  • 配置在全局，影响了公司内网仓库。

五、取消代理

不需要时用对应的 unset 命令撤销设置，避免遗留配置导致其他问题。

小结

先分清地址类型，再选对应设置，克隆速度通常会有明显改善。
